Sanurhasta design system.

The rules behind the Sanurhasta corporate site: logo, colour, type, spacing, grid, shape, elevation and voice. Every size and space is a multiple of 4, and every text pairing is checked against WCAG 2.2 Level AAA.

Build on 4

Font sizes, line heights, spacing, radii, icon boxes and shadow offsets all step in 4px increments.

Keep it symmetrical

Equal padding on opposite sides, equal margins left and right, and a centred 12-column grid.

Let it breathe

Use space, not boxes, to group content. Hairlines separate list rows; whitespace separates sections.

04 · Typography

Four header levels, snapped to 4.

Headings grow with the viewport and are rounded to the nearest 4px, so every rendered size is on the grid. Line height is the font size plus 4px or 8px. Samples below render at your current width ({{ vw }}px).

Line height ruleLine height = font size + 4px or + 8pxOnly two options. Large headlines, numerals and 12px caps add 4px for tight, compact lines. Everything people read in sentences adds 8px for comfortable spacing. Because every size is a multiple of 4, both keep every line on the 4px grid. In code it is written as line-height: calc(1em + 8px), so it follows the fluid size automatically.

08 · Shape & corner radius

Soft corners, pill actions.

Containers use 24px corners. Anything you press is a pill or a circle. The arch is reserved for featured property imagery. Nested corners follow inner radius = outer radius − padding.
